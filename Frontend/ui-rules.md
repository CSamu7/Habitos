# Comentarios

Solo comenta bloques de codigo relevantes.
Los comentarios solo responderan ¿Por que tomaste esta decisión?.

# Componentes React

De acuerdo al diseño, siempre trata de buscar el componente correspondiende. Si no encontraste uno, entonces pregunta si puedes crear un nuevo componente o el nombre del componente.

# CSS

- Siempre usa los colores que esten en el :root de index.css. Si no encuentras algun color parecido, añade un color en :root con un comentario indicando que es el nuevo color que se creo.

- No uses :global

# Testing

No trates de comprobar los cambios en el Frontend.
